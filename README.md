# Physics Question Bank
This repository houses the master question library (`physics_questions_data.js`) for my physics review app builder. The file holds the questions, their answers and guided solutions, and the code that draws their diagrams.

## Files
- `index.html` and `library/index.html`: the Physics Question Library and Constructor (Teacher Studio v63). Both are the same app.
- `physics_questions_data.js`: the question library.
- `fbd_scenarios_data.js`, `fbd_student_app.js`, `fbd_builder.js`: the Free-Body Diagram scenarios, student app and builder. The library app loads these from this repository when you choose Free-Body Diagrams.
